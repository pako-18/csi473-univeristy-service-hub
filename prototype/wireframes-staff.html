Academic staff wireframes: check a student's completion status

Low-fidelity wireframes for the secondary task in docs/user-profile-and-tasks.md (section 4). Every state is described in docs/ui-states.md. Dashed boxes are content placeholders. Yellow notes are annotations and are not part of the screen. Staff use the same Sign in screen as students (FR-01, role-based access), so it is not repeated here.

Main flow

Step 1: Student lookup

Check student status

Enter a student ID to see their completion status.

Looking up student… (loading state)
Sign out
FR-02, UC-03, UC-09One field and one action. The label stays visible. The loading message is announced to screen readers. Reachable by keyboard with a visible focus outline.

Step 2 (eligible): Result

Student [ID]: [Name]

✔ Eligible: all requirements met.
Programme: [name]
Credits earned: [n] of [n]
Record last updated: [date]
View issued letter (shown only if a letter has been issued)
FR-03, FR-04, FR-08, UC-10Status is shown with a tick and the word "Eligible", not colour alone. The letter link appears only when a letter exists.

Step 2 (not eligible): Result

Student [ID]: [Name]

✖ Not eligible: requirements outstanding.
  • ✖ Credits: [n] more needed
  • ✖ Compulsory module: [code, name]
  • ✔ Elective credits: met
Record last updated: [date]
FR-04 to FR-07, UC-10Each unmet item is listed on its own line, so staff can tell the student exactly what is missing. Met and unmet items are marked by icon and word.

Alternative states

Validation: empty ID

Check student status

✖ Enter a student ID.
QS-6, QS-7The message sits under the field and keyboard focus returns to it. Wrong format: "Student ID must contain digits only."

Error: student not found

Check student status

✖ No student found with ID [ID]. Check the ID and try again.
UC-03The ID the user typed stays in the field so they can correct it.

Unavailable: records system down

Check student status

⚠ Student records are temporarily unavailable. Please try again later.

No status is shown, and nothing is guessed.

FR-02, UC-03 alt. flow, QS-4Warning uses an icon, a double-line border and words. No stale status is presented as current.
