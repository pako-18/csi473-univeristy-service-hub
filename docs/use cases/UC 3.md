Use Case 3: View Outstanding Requirements

Primary Actor:Student

Supporting Actor
:Academic Staff

Goal-The student wants to identify any outstanding credits, modules, or programme requirements that must be completed before they can graduate.

Preconditions

-The student has a registered academic record.
-The student's programme is recorded in the system.
-The programme's required credits and modules are available.
-The student's completed academic information is available.
-The student has successfully authenticated.

Postconditions

-The system compares the student's completed requirements with the programme requirements.
-The system identifies outstanding credits or modules.
-The system displays the outstanding requirements to the student.
- The system confirms that all programme requirements have been satisfied.
- The system informs the student that there are no outstanding requirements.

Main Success Flow

-The student logs into the system.
-The student selects the option to view outstanding requirements.
-The system retrieves the student's academic record.
-The system retrieves the student's programme requirements.
-The system identifies the credits and modules completed by the student.
-The system compares the completed requirements with the programme requirements.
-The system identifies any outstanding credits.
-The system identifies any outstanding required modules.
-The system displays the outstanding requirements to the student.

Alternative Flows

1.No Outstanding Requirements

-The system compares the student's completed requirements with the programme requirements.
-The system determines that all required credits have been completed.
-The system confirms that all required modules have been completed.
-The system informs the student that there are no outstanding requirements.
-The system identifies the student as eligible for completion.

2.Outstanding Credits

-The system compares the student's completed credits with the required credits.
-The system determines that the student has not reached the required credit total.
-The system calculates the number of outstanding credits.
-The system displays the outstanding credit requirement to the student.

 3.Outstanding Required Modules

-The system checks the student's completed modules.
-The system identifies one or more required modules that have not been completed.
-The system lists the outstanding modules.
-The system displays the outstanding modules to the student.

4.Programme Requirements Unavailable

-The system attempts to retrieve the programme requirements.
-The programme requirements cannot be retrieved.
-The system displays an appropriate error message.
-The system informs the student that outstanding requirements cannot currently be calculated.
