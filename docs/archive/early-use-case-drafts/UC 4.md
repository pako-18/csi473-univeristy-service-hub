USE CASE 4: Access Completion Letter


Primary Actor:Student

Supporting Actor:Academic Staff

Goal:The student wants to access their completion letter after the system confirms that all programme requirements have been satisfied.

 Preconditions

1. The student has a registered academic record.
2. The student has successfully authenticated.
3. The student's completion status has been determined.
4. The student has satisfied all required credits.
5. The student has completed all required programme modules.
6. The student is eligible for a completion letter.

 Postconditions

Success

1. The system confirms the student's completion eligibility.
2. The system generates or retrieves the student's completion letter.
3. The completion letter is made available to the student.

Main Success Scenario

1. The student logs into the system.
2. The student requests to access their completion letter.
3. The system retrieves the student's completion status.
4. The system confirms that the student has completed all required credits.
5. The system confirms that all required modules have been completed.
6. The system confirms that the student is eligible for completion.
7. The system generates or retrieves the student's completion letter.
8. The system makes the completion letter available to the student.
9. The student accesses the completion letter.

Alternative Flows

### A1 — Student Has Outstanding Requirements

1. The student requests their completion letter.
2. The system checks the student's completion status.
3. The system determines that the student has outstanding credits or modules.
4. The system does not generate or provide the completion letter.
5. The system displays the outstanding requirements to the student.

### A2 — Completion Status Cannot Be Determined

1. The student requests their completion letter.
2. The system attempts to determine the student's completion status.
3. The system cannot retrieve the required academic information.
4. The system displays an error message.
5. The system does not generate the completion letter.

### A3 — Completion Letter Cannot Be Generated

1. The system confirms that the student is eligible for completion.
2. The system attempts to generate the completion letter.
3. The completion letter cannot be generated.
4. The system displays an appropriate error message.
5. The system informs the student that the letter is temporarily unavailable.
