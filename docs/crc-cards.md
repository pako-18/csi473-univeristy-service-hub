Card 2: Academic Record

Class
Academic Record — the official record of a student's academic history

Responsibilities
Maintains the student's academic information.
Records completed module results and associated credit values.
Supplies this information whenever credit totals need to be calculated.
Enables comparison between completed credits/modules and programme requirements.
Is updated only by authorised academic staff.
Automatically triggers a recheck of completion status whenever it is updated.

Card 3: Programme Requirement

Class
Programme Requirement — the defined criteria a student must meet to complete their programme

Responsibilities

Specifies the total credits required for the programme.
Specifies which modules are compulsory.
Supplies these requirements whenever an eligibility check is carried out.
Helps identify any outstanding credits or modules.
Determines whether a student has satisfied all programme requirements.

Card 4: Completion Letter

Class
Completion Letter — official confirmation that a student has completed their programme

Responsibilities

Confirms the student's eligibility before being issued.
Is generated or retrieved once all requirements have been satisfied.
Is made available to the student once eligibility is confirmed.
Remains inaccessible while outstanding requirements exist.
